# AI BUDDY 顧客管理ポータル

株式会社ATIS「AI伴走支援サービス」の顧客・担当者・スケジュール管理SPA。

## 概要

- 担当者管理（追加・削除・カラー設定）
- 顧客登録・編集・削除
- 週次スケジュール管理（繰り返し予定対応）
- ダッシュボード（MRR・クライアントヘルス）
- 売上管理（月次レポート）
- レスポンシブ対応（PC・モバイル）

## 使い方

`index.html` をブラウザで開くだけで動作します。サーバー不要。

## 技術スタック

- HTML / CSS / Vanilla JS（単一ファイルSPA）
- Google Fonts（Inter, IBM Plex Mono）
- 外部依存なし
